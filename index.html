Lesson 1: What is HTML?

HTML stands for Hyper Text Markup Language. It is known as the skeleton of the webpage. The CSS language is known as the skin that cloths the skeleton.

HTML creates the structure of a webpage, while CSS controls its appearance.

Example

<p>Hello World</p>

p {
    color: blue;
    font-size: 30px;
}

Lesson 2: CSS Selectors

Selectors tell CSS which HTML elements should receive a style.

Element Selector

p {
    color: red;
}

This selects every <p> element.

Class Selector

.title {
    color: green;
}

Classes start with a period ..

ID Selector

#header {
    background: black;
}

IDs start with the # symbol.

This is a CSS example.

Lesson 4: The CSS Box Model

Every HTML element can be thought of as a box.

The box model contains:

  • Content
  • Padding
  • Border
  • Margin
.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    margin: 30px;
}

Lesson 5: CSS Flexbox

Flexbox is used to arrange elements in rows or columns. 

.container {
    display: flex;
    justify-content: center;
    gap: 20px;
}
